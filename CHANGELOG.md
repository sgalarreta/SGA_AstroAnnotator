# Changelog

## 1.0.0 - 2026-10-13

First public release of SGA_AstroAnnotator.

Includes object names, coordinates, and logo compositing; interactive preview; stacked or independent text blocks; alignment relative to the logo; reusable layout presets; five interface languages; WCS coordinate reading and manual coordinate entry; a Buy Me a Coffee button; and a check that the image has not changed before applying annotations.

Settings are stored in `~/.SGA_astroannotator/settings.json`. Previously saved development-version presets can be migrated automatically.
